### Paid micro-consulting: AI agent workflow audit

I am opening a small number of async micro-consulting slots for builders and small teams using Claude Code, Codex, Cursor, Copilot, or custom coding-agent workflows.

I can help when:

- agent runs keep producing duplicate PRs, stale plans, or work that misses acceptance criteria;
- repo instructions are split across `README.md`, `AGENTS.md`, `CLAUDE.md`, prompts, and issue comments;
- maintainers want lightweight guardrails before adding heavier automation;
- a team needs clearer issue templates, PR checklists, review gates, or handoff docs.

Typical deliverables:

- **Repository workflow audit** — written findings + priority fixes, from **KRW 50,000**
- **Agent-ready issue / PR template setup** — templates and review checklist, from **KRW 80,000**
- **Async workflow review** — 1 focused review pass + recommendations, from **KRW 120,000**

Start here:

- Read a sample deliverable: [`sample-agent-workflow-audit.md`](./sample-agent-workflow-audit.md)
- Open a safe public inquiry: [new paid inquiry issue](https://github.com/steadfastree/steadfastree/issues/new?template=paid-inquiry.yml)

Please do **not** include secrets, private keys, customer data, or private source code in a public GitHub issue. Payment and private details are handled manually after scope is confirmed.
